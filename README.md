# ✨ Device Features App (Fairy Edition) 🧚‍♀️

This React Native application was developed as part of the **Mobile Programming Lab 7** assignment. It integrates native device features including Camera, Gallery, GPS, and Notifications. Instead of the standard interface, a custom **"Fairy Theme"** (soft colors and custom UI) has been applied.

## 🚀 Project Features
* **Camera & Gallery:** Capture photos or select images from the gallery (integrated with Haptic feedback).
* **Location Service:** Retrieve current GPS coordinates.
* **Notifications:** Trigger local notifications upon successful location retrieval.
* **Custom Design:** Aesthetic Linear Gradient backgrounds and customized soft buttons.
